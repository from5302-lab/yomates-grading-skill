**'우리 학원 채점 규칙' 스킬**이에요. 숙제·시험지 사진을 보내면 정답지와 대조해 채점표를 만들고, 틀린 문제만 다시 풀 문제지와 월말 성적표까지 만들어요. 쌤이 "이건 이렇게 채점해"라고 말씀하시면 그 말이 스킬 안에 규칙으로 쌓여서 다음 채점부터 그대로 지켜져요. 학원 쌤들이 쓰도록 만들었어요.

스킬 맨 위에 두 칸이 있어요.
- **우리 학원 설정:** 학원 이름, 학년, 과목, 반 이름, 학생 별명 목록(실명 대신), 정답지 위치, 배점, 서술형 부분점수 기준, 통과선, 기록 폴더, 성적표 주기, 로고, 대표 색. 비어 있으면 처음 쓸 때 한 번에 물어보고 채워 저장해요.
- **우리 학원 규칙:** 채점표를 보고 "이건 이렇게 채점해"라고 하실 때마다 한 줄씩 더해져요. 예: `문장 첫 글자 대문자·마침표는 감점하지 않는다.`

하는 일은 이 순서예요.
1. 답안지 사진을 읽어요. 못 읽은 글자는 `[?]`, 지운 자국이 남은 답은 '애매'로 두고 쌤 확인 목록에 올려요. **애매한 답은 AI가 정하지 않아요.**
2. 정답지와 대조해 학생 × 문항 채점표를 만들어요. 서술형은 기준마다 부분점수를 매기고 깎은 이유를 한 줄씩 적어요. 한 실수로 여러 기준이 같이 틀리면 한 번만 깎아요. 합계는 가로·세로로 두 번 검산해요. 그다음 쌤 확인 목록을 여쭙고, 답을 받아 점수를 확정해요. 답을 못 받은 문항은 '보류'로 두고 확정 점수만 써요.
3. 학생별 오답 정리를 만들어요. 틀린 문항, 문법 포인트, 지난번에도 틀렸는지, 반 전체에서 많이 틀린 문항이 들어가요.
4. 틀린 문제만 같은 문법·새 문장으로 다시 풀 문제지를 만들어요. 직접 다시 풀어 답이 하나인지 확인해요. [우리 학원 문제지 규칙](https://github.com/from5302-lab/yomates-worksheet-skill) 스킬이 있으면 그 스킬의 문제 유형과 정답 검증을 그대로 쓰고, 색과 모양은 이 스킬 설정을 따라요.
5. 학생별 기록 파일에 한 줄씩 쌓고, 월말에 학생마다 A4 한 장 성적표를 뽑아요. 점수 추이, 잘한 것·더 할 것, 다음 달 계획이 들어가요.
6. 학부모 안내 문자는 **초안까지만** 만들어요. 보내는 건 쌤이 확인하고 직접 하세요.

크레딧은 들지 않아요. 그림 생성이나 유료 기능을 쓰지 않고, PDF는 컴퓨터 안에서 크롬으로 만들어요.

## 설치

요메이트 팀원에게 이렇게 보내요. 팀원이 저장소를 통째로(틀 4개까지) 가져와요.
> 이 깃허브 저장소를 스킬로 가져와 줘: https://github.com/from5302-lab/yomates-grading-skill

가져오기가 안 된다고 하면 그때만 이렇게 보내요.
> https://github.com/from5302-lab/yomates-grading-skill 의 SKILL.md 읽고 '우리-학원-채점-규칙' 스킬로 저장해 줘. 그다음 처음 쓰는 순서대로 해 줘.

처음 한 번은 '우리 학원 설정'의 빈 칸을 한 번에 물어봐요. 답하시면 스킬에 채워 저장하고 다음부터는 묻지 않아요. 나중에 "스킬 업데이트해 줘"라고 하셔도 쌤의 설정과 규칙, 학생 기록은 그대로 남아요.

## 이렇게 부탁하세요

1. > (답안지 사진 3장을 붙이고) 중2 A반 오늘 숙제야. 2강 문제지 정답으로 채점해 줘. 첫 장부터 도토리, 구름, 민트야.
2. > 틀린 문제만 학생마다 다시 풀 문제지 만들어 줘. 같은 문법으로 새 문장으로.
3. > 이번 달 성적표 뽑아 줘. 그리고 철자 하나 틀린 건 다음부터 1점만 빼.

## 개인정보

- 학생은 실명 대신 **별명**으로만 불러요. 별명과 실명의 짝은 쌤만 아시고, 스킬·메모·파일 어디에도 적지 않아요.
- 답안지 사진 속 이름은 글로 옮기지 않아요. 사진을 남겨야 하면 이름 칸을 가린 사본만 남겨요.
- 채점표·기록·성적표는 쌤 컴퓨터 안 기록 폴더에만 둬요.
- 모든 결과물 아래에 작게 'AI 채점 · 쌤 최종 확인'이 들어가요.

## 예시 (`examples/`)

2강 [우리 학원 문제지 규칙](https://github.com/from5302-lab/yomates-worksheet-skill)의 중2 영어 시험지형 문제지(40점)를 학생 3명(별명)이 풀었다고 보고 채점한 예시예요. 설정과 규칙은 `중2-영어-설정-예시.md` 에 있어요.

| 파일 | 무엇 |
|---|---|
| `답안지-도토리.png` · `답안지-구름.png` · `답안지-민트.png` | 손글씨 글꼴로 만든 답안지 예시. 서로 다른 실수, 지운 자국 하나, 번진 글자 하나가 들어 있어요 |
| `채점표.pdf` | 학생 × 문항, 서술형 부분점수와 깎은 이유, 쌤 확인 목록 (37 · 23 · 23점) |
| `오답-정리.pdf` | 반 전체 정답률과 다시 짚을 것, 학생별 오답 |
| `다시-풀기-문제지.pdf` | 학생마다 틀린 문항만 새 문장으로 한 장씩 + 정답·해설 |
| `기록/` | 학생별 기록 파일 (11-04~11-18 줄은 성적표 모양을 보여 드리려고 만든 예시 값) |
| `월말-성적표.pdf` | 11월 성적표, 학생마다 한 장 |
| `학부모-안내-초안.md` | 보내지 않은 문자 초안 |
| `검증-기록.md` | 검산, 다시 풀기 검증, 성적표 숫자 대조 |
