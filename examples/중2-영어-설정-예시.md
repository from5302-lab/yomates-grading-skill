# 예시: 중2 A반 영어로 채운 '우리 학원 설정'과 '우리 학원 규칙'

이 폴더의 예시 파일은 모두 아래 설정과 규칙으로 만들었어요. 스킬을 처음 쓰실 때 이렇게 한 번 채워지고, 그 뒤로는 다시 묻지 않아요.

## 우리 학원 설정

<!-- school-settings:start -->
| 칸 | 우리 학원 값 |
|---|---|
| 학원 이름 | ○○영어학원 |
| 학년 | 중2 |
| 과목 | 영어 |
| 반 이름 | 중2 A반 |
| 학생 별명 목록 | 도토리, 구름, 민트 |
| 정답지 위치 | 문제지 규칙 스킬 정답·해설 쪽 (`yomates-worksheet-skill/examples/중2-영어-5문제-exam.pdf` 2쪽) |
| 배점 | 정답지에 적힌 배점을 따름 (객관식 7점 × 4, 서술형 12점, 40점 만점) |
| 서술형 부분점수 기준 | 정답지의 채점 기준을 따름 (비교급 steeper 3 · 강조하는 말 3 · than we expected 3 · 8단어 3) |
| 통과선 | 40점 만점에 28점 (70%) |
| 기록 폴더 | ~/학원채점/중2A반 |
| 성적표 주기 | 월말 |
| 학원 로고 | (없음) |
| 대표 색 | #1f4e8c |
<!-- school-settings:end -->

## 우리 학원 규칙

<!-- school-rules:start -->
- 객관식에 지운 자국이 있으면 마지막에 진하게 표시한 답으로 본다. 둘 다 진하면 쌤께 묻는다. (11-25)
<!-- school-rules:end -->

위 규칙 한 줄은 11-25 채점 때 쌤 확인 목록에서 생겼어요. 도토리 4번에 ①과 지운 ②가 함께 있어서 AI가 정하지 않고 여쭸고, 쌤이 "마지막에 진하게 쓴 걸로 봐"라고 하셔서 규칙으로 쌓았어요. 다음 채점부터는 같은 경우를 묻지 않아요.

## 예시 파일

| 파일 | 무엇 |
|---|---|
| `답안지-도토리.png`, `답안지-구름.png`, `답안지-민트.png` | 학생 3명이 2강 시험지형 문제지를 푼 답안지(손글씨 글꼴로 만든 예시 사진) |
| `채점표.pdf` | 학생 × 문항 채점표, 5번 서술형 부분점수와 깎은 이유, 쌤 확인 목록 |
| `오답-정리.pdf` | 반 전체 문항별 정답률과 수업 때 다시 짚을 것, 학생별 오답(지난번에도 틀렸는지 포함) |
| `다시-풀기-문제지.pdf` | 학생마다 틀리거나 감점된 문항만, 같은 문법 새 문장으로 한 장씩 + 정답·해설 |
| `기록/도토리.md` 등 | 학생별 기록 파일. 11-25 줄이 이번 채점, 11-04~11-18 줄은 성적표 모양을 보여 드리려고 만든 예시 값 |
| `월말-성적표.pdf` | 기록 4주로 만든 11월 성적표, 학생마다 한 장 |
| `학부모-안내-초안.md` | 성적표와 함께 보낼 문자 초안(보내지 않음, 이름 자리는 쌤이 채움) |
| `검증-기록.md` | 채점 검산, 다시 풀기 문제 검증, 성적표 숫자 대조 |

학생 별명과 점수는 모두 예시예요. 실제 학생 정보는 들어 있지 않아요.
