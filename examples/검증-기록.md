# 검증 기록: 중2 A반 11-25 채점 예시

스킬 순서(2~8단계)대로 돌리면서 확인한 것을 남겨요.

## 2단계 정답지 표 (문제지 규칙 스킬 정답·해설 쪽에서 가져옴)

| 문항 | 정답 | 배점 | 채점 기준 · 이렇게 써도 정답 | 문법 포인트 |
|---|---|---|---|---|
| 1 | ② | 7 | | plan + to부정사 |
| 2 | ① | 7 | | 접속사 so |
| 3 | ③ | 7 | | 내용 일치 |
| 4 | ① | 7 | | 글의 순서(가리키는 말) |
| 5 | The road was much steeper than we expected. | 12 | steeper 3 · 강조하는 말 3 · than we expected 3 · 8단어 3 / much 대신 even, far, still도 정답, very는 틀림 | 비교급 강조·형태 |

배점 합 7 × 4 + 12 = 40, 문제지 머리 '총 40점'과 같음.

## 3단계 읽은 답

| 학생 | 1 | 2 | 3 | 4 | 5 (쓴 그대로) |
|---|---|---|---|---|---|
| 도토리 | ② | ① | ③ | **애매**: ①에 동그라미, ②에 지운 동그라미 자국 | The road was very steeper than we expected. |
| 구름 | ⑤ | ③ | ③ | ① | The road was much more steep than we expected. |
| 민트 | ② | ③ | ③ | ③ | The road was even steeper than we expect[?] (끝이 번져 -ed 여부가 안 보임) |

쌤 확인 목록 2개를 여쭘:
1. 도토리 4번 → 쌤 확인: 마지막에 진하게 쓴 ① 인정. "다음에도 이렇게 볼까요?"에 예 → 규칙에 더함.
2. 민트 5번 `expect[?]` → 쌤 확인: 원본 종이에 expect로 씀. than we expected 기준 0점.

## 4단계 채점 검산

| 학생 | 1 | 2 | 3 | 4 | 5 | 합계 |
|---|---|---|---|---|---|---|
| 도토리 | 7 | 7 | 7 | 7 | 9 (3·0·3·3) | 37 |
| 구름 | 0 | 0 | 7 | 7 | 6 (0·3·3·0) | 20 |
| 민트 | 7 | 0 | 7 | 0 | 9 (3·3·0·3) | 23 |
| 문항 합계 | 14 | 7 | 21 | 14 | 24 | 80 |

- 가로 합 37 + 20 + 23 = 80, 세로 합 14 + 7 + 21 + 14 + 24 = 80. 같음.
- 서술형 단어 수: 도토리 8단어, 구름 9단어(The road was much more steep than we expected), 민트 8단어. 하나씩 셈.
- 통과선 28: 도토리 통과, 구름·민트 다시 풀기. 평균 80 ÷ 3 = 26.7점.

## 6단계 다시 풀기 검증

학생마다 정답을 보지 않고 다시 풀었어요. '노출'은 같은 장의 다른 문제에 답 모양 그대로 나오는지예요.

| 학생 | 문제 | 정답 | 답이 하나인가 | 노출 | 단어 수 |
|---|---|---|---|---|---|
| 도토리 | 1 very colder 고치기 | much colder (even·far·still) | 강조하는 말 넷 다 정답으로 해설에 적음 | 2번에 colder 없음 | |
| 도토리 | 2 서술형 easy | This test was much easier than the last one. | 조건 지키는 답은 강조하는 말만 바뀜 | 1번에 easier 없음 | **9단어**. 처음에 '8단어'로 냈다가 세어 보니 9단어라 조건을 9단어로 고침 |
| 구름 | 1 어법 틀린 문장 | ② decided going | ① wants to ③ the hottest … of the year ④ hope to ⑤ enjoy reading 모두 맞음 | | |
| 구름 | 2 promised (to call / calling) | to call | promise + to부정사만 | 1번에 to call 없음 | |
| 구름 | 3 hungry, ___ I made | ① so | because는 앞뒤가 바뀜, but·although는 반대가 아님 | 4번 보기에 so가 있지만 보기 중 하나라 괜찮음 | |
| 구름 | 4 stayed home ___ raining | ② because | so는 원인·결과가 뒤집힘 | | |
| 구름 | 5 (heavier / more heavy) | heavier | | 6번 답 wider와 다름 | |
| 구름 | 6 서술형 wide | The river was much wider than we thought. | | 5번 괄호에 wider 없음 | 8단어 |
| 민트 | 1 rain, ___ we went back | ② so | | | |
| 민트 | 2 쿠키 순서 | ③ (B)-(A)-(C) | First·Then·After twenty minutes, the dough가 (B) 다음 | | |
| 민트 | 3 화분 순서 | ④ (B)-(C)-(A) | First가 (B)를 앞에, Now가 (A)를 끝에 고정 | | |
| 민트 | 4 Last week, I (think / thought) | thought | | 5번 답 expected와 다른 동사로 냄(처음 안은 expect / expected였는데 5번 답을 알려 줘서 바꿈) | |
| 민트 | 5 서술형 long | The movie was much longer than we expected. | | | 8단어 |

원래 문제와 같은 문장·보기는 없음. 정답 번호는 학생마다 섞임.

## 8단계 성적표 숫자 대조

| 학생 | 기록 파일 점수 | 성적표 꺾은선·표 | 평균(직접 더함) | 통과 |
|---|---|---|---|---|
| 도토리 | 30, 33, 35, 37 | 같음 | 135 ÷ 4 = 33.75 | 4/4 |
| 구름 | 24, 21, 26, 20 | 같음 | 91 ÷ 4 = 22.75 | 0/4 |
| 민트 | 22, 25, 27, 23 | 같음 | 97 ÷ 4 = 24.25 | 0/4 |

'많이 틀린 문법'의 횟수는 기록 파일 '문법 포인트' 칸에서 셈(예: 민트 과거 시제 11-04·11-11·11-18·11-25 = 4번). 잘한 것·더 할 것은 기록에 있는 점수·횟수·다시 풀기 결과로만 씀.
